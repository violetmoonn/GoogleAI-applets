# AI builds

Two projects:

- **[custom-agent/](custom-agent/)** — a customizable Claude agent for the terminal. Each agent's model, effort, system prompt and tools live in a YAML file; add tools by dropping Python files in `plugins/`.
- **[ai-studio/](ai-studio/)** — upgrade plan for Google AI Studio Build projects:
  - `AI-Studio-Upgrade-Guide.md` — 48 paste-ready AI Studio Build prompts (duplicates merged), each with comparison tests vs ChatGPT and Claude
  - `ai-studio-upgrades.html` — the same guide as a page with copy buttons, search and a progress tracker (open it in a browser)
  - `upgrades/` — the guide split by group

Personal details are replaced with placeholders such as `[Your Name]`, `[YOUR BRAND]`, `[your neighborhood]` and `[practice name]`. Fill them in before pasting a prompt.
