Upgrade prompts for every project

About 70 saved projects, with duplicates merged into 48 rebuilds. Each one has a prompt to paste into AI Studio Build and three tasks to run against ChatGPT and Claude.

  1. Copy a prompt and open aistudio.google.com → Build.
  2. Paste it into the original project, or start a new app for a clean rebuild.
  3. Pick the newest Gemini Pro model, then run the three comparison tasks.
  4. Tick Rebuilt here so you can see your progress.
Prompts name "the newest Gemini model" instead of a version, so they stay current. Sections marked Reframed were changed so the app works reliably and legitimately.
